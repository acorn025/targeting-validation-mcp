# Ad Targeting Assistant MCP Server

자연어 기반의 광고 타겟팅 입력을 분석하여 표준 마케팅 데이터로 변환하고, 설정의 유효성을 실시간으로 검증하는 MCP 서버입니다.

## 🚀 주요 기능
- **입력 누락 방지:** 필수 타겟팅 항목(연령, 성별, 관심사, 지역)의 입력 여부를 체크합니다.
- **논리적 정합성 확인:** 선택한 지역과 관심사 키워드가 서로 모순되지 않는지 기술적으로 검토합니다.
- **가이드라인 참조:** 특정 연령대 및 관심사 조합 시 참고할 만한 주의 사항을 안내합니다.
- **데이터 표준화:** 입력값을 시스템 처리에 적합한 규격(대문자 등)으로 정규화합니다.

## 🛠️ 테스트 예시 (심사 가이드)
심사 시 아래 문구들을 입력하여 도구의 동작을 확인할 수 있습니다.

1. "경기 30대 남성, 캠핑·아파트 타겟 검토해줘."
2. "40대 성별무관으로 건강식품 타겟 설정 확인해줘."
3. "부산 지역 30대 여성, 외국어 관심사 조합 확인해줘."
