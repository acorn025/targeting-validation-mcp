# 🚀 Ad Targeting Assistant (광고 타겟팅 검증 및 분석 엔진)

AI 에이전트가 광고 타겟팅의 논리적 오류를 검토하고, 소비자 페르소나를 즉석에서 분석할 수 있도록 돕는 **FastMCP 기반의 백엔드 도구**입니다.

## 📌 프로젝트 개요
마케팅 캠페인 설정 시 흔히 발생하는 **타겟 설정 오류(예: 60대에게 청년 정책 광고)**를 사전에 방지하고, 특정 키워드에 최적화된 소비자 군을 정의하기 위해 개발되었습니다. LLM(Large Language Model)이 호출하여 사용할 수 있는 기능(Tool) 형태로 설계되었습니다.

## ✨ 주요 기능

### 1. 타겟팅 정합성 검증 (Validation Mode)
* **연령-상품 정합성:** 입력된 관심사(예: 청년도약계좌, 실버 복지 등)와 설정된 타겟 연령대가 비즈니스 로직상 일치하는지 검증합니다.
* **지역 데이터 무결성:** 시/도와 시/군/구 간의 행정구역 포함 관계를 분석하여 지역 설정 오류를 찾아냅니다.
* **광고 정책 준수:** 미성년자 대상 주류, 사행성 키워드 타겟팅 등 플랫폼별 금지 정책 위반 여부를 자동 모니터링합니다.

### 2. 페르소나 분석 및 제언 (Analysis Mode)
* **데이터 기반 분석:** 내부 DB(`PERSONA_DB`)를 참조하여 특정 상품군에 대한 핵심 소비자 정의, 연령 트렌드, 라이프스타일을 도출합니다.
* **AI 확장성:** 구체적인 타겟 정보가 부족할 경우, AI가 연관 관심사와 타겟팅 힌트를 생성할 수 있도록 구조화된 가이드를 반환합니다.

## 🛠 기술 스택
* **Framework:** `FastMCP` (Model Context Protocol)
* **Language:** `Python 3.9+`
* **Core Logic:** 정규표현식(`re`) 기반의 자연어 파싱 및 룰 기반 검증 엔진(Rule-based Engine)

## 💡 핵심 코드 로직
* **Mode Switching:** 사용자 입력값의 완성도에 따라 '페르소나 분석'과 '정밀 검증' 모드를 자동으로 전환하여 응답합니다.
* **Data Normalization:** "남성", "F", "20대", "34세 이하" 등 다양한 형태의 입력을 표준화된 데이터(Normalized Data)로 변환하여 처리합니다.
